## 服务详情与服务列表

提供一个服务的概念，资产中的应用改为服务 服务可以是业务上的概念，可以是一个应用，也可以是多个应用。

在纳管页面的叫做服务，在未纳管页面是应用。

服务有如下字段：

1. 服务名、运行状态、实例数量、部署方式、实例列表、服务类型，服务类型有web服务和非web类型。
2. 应用有三种部署方式：systemd、k8s、docker。 2.1 添加服务时，根据部署方式的不同，会有不同的表单。
    - systemd: 提供system文件名绑定，可以选择多台主机的多个system实例作为一个服务
    - docker: 提供容器名，或者标签key，values作为服务绑定，可以选择多态主机的多个实例作为一个服务。
    - k8s: 需要先选择控制器类型，然后选择控制器名。作为一个服务。
3. 每个实例的CPU和内存使用情况，以及实例日志。
4. 除了实例日志，还可以添加日志源，
5. 当服务是web类型是，会有一个额外的tab，叫做接口。
6. 同样，服务也有告警

# 详细设计

## 主机

指标列表：

| 指标类别 | 指标名称 | Prometheus 表达式 | 单位 |
| --- | --- | --- | --- |
| 基本信息 | 主机名 | `node_uname_info{host_ip="$host_ip",host_name="$host_name"}`，取 `nodename` 标签 | - |
| 基本信息 | 内网 IP | `count by (host_ip) (node_uname_info{host_ip="$host_ip",host_name="$host_name"})`，取 `host_ip` 标签 | - |
| 基本信息 | 外部 IP | 非 node-exporter 指标，使用资产元数据 | - |
| 基本信息 | 所属地 | 非 node-exporter 指标，使用资产元数据 | - |
| 基本信息 | 纳管状态 | 非 node-exporter 指标，使用资产元数据 | - |
| 基本信息 | CPU 核数 | `count(node_cpu_seconds_total{mode="idle",host_ip="$host_ip",host_name="$host_name"})` | 核 |
| 基本信息 | 内存总量 | `node_memory_MemTotal_bytes{host_ip="$host_ip",host_name="$host_name"}` | bytes |
| 基本信息 | 系统盘总大小 | `node_filesystem_size_bytes{mountpoint="/",host_ip="$host_ip",host_name="$host_name"}` | bytes |
| 基本信息 | 操作系统 | `node_os_info{host_ip="$host_ip",host_name="$host_name"}`，取 `pretty_name` 标签 | - |
| 监控概要 | 系统盘已使用空间 | `node_filesystem_size_bytes{mountpoint="/",host_ip="$host_ip",host_name="$host_name"} - node_filesystem_avail_bytes{mountpoint="/",host_ip="$host_ip",host_name="$host_name"}` | bytes |
| 监控概要 | 系统盘使用率 | `100 * (1 - node_filesystem_avail_bytes{mountpoint="/",host_ip="$host_ip",host_name="$host_name"} / node_filesystem_size_bytes{mountpoint="/",host_ip="$host_ip",host_name="$host_name"})` | % |
| 监控概要 | CPU 使用率 | `100 * (1 - avg by (host_ip, host_name) (rate(node_cpu_seconds_total{mode="idle",host_ip="$host_ip",host_name="$host_name"}[5m])))` | % |
| 监控概要 | 内存已使用量 | `node_memory_MemTotal_bytes{host_ip="$host_ip",host_name="$host_name"} - node_memory_MemAvailable_bytes{host_ip="$host_ip",host_name="$host_name"}` | bytes |
| 监控概要 | 公网带宽入站速率 | `sum by (host_ip, host_name) (rate(node_network_receive_bytes_total{device!="lo",host_ip="$host_ip",host_name="$host_name"}[5m])) * 8` | bits/s |
| 监控概要 | 公网带宽出站速率 | `sum by (host_ip, host_name) (rate(node_network_transmit_bytes_total{device!="lo",host_ip="$host_ip",host_name="$host_name"}[5m])) * 8` | bits/s |
| 监控概要 | 系统盘读取速率 | `sum by (host_ip, host_name) (rate(node_disk_read_bytes_total{device="vda",host_ip="$host_ip",host_name="$host_name"}[5m]))` | bytes/s |
| 监控概要 | 系统盘写入速率 | `sum by (host_ip, host_name) (rate(node_disk_written_bytes_total{device="vda",host_ip="$host_ip",host_name="$host_name"}[5m]))` | bytes/s |
| 监控概要 | 活跃告警总数 | 非 node-exporter 指标，使用 Prometheus 告警规则或告警系统数据 | 条 |
| 监控概要 | 高优先级告警数 | 非 node-exporter 指标，使用 Prometheus 告警规则或告警系统数据 | 条 |
| 监控概要 | 中优先级告警数 | 非 node-exporter 指标，使用 Prometheus 告警规则或告警系统数据 | 条 |
| 监控概要 | 低优先级告警数 | 非 node-exporter 指标，使用 Prometheus 告警规则或告警系统数据 | 条 |
| 服务排行 | 服务 CPU 使用率 | node-exporter 不提供进程/服务维度指标，需增加 process-exporter 或其他采集器 | % |
| 服务排行 | 服务内存使用率 | node-exporter 不提供进程/服务维度指标，需增加 process-exporter 或其他采集器 | % |
| 资源趋势 | CPU 使用率趋势 | 使用“CPU 使用率”表达式进行范围查询，粒度由时间范围决定 | % |
| 资源趋势 | 内存使用率趋势 | `100 * (1 - node_memory_MemAvailable_bytes{host_ip="$host_ip",host_name="$host_name"} / node_memory_MemTotal_bytes{host_ip="$host_ip",host_name="$host_name"})`，进行范围查询 | % |
| 资源趋势 | 网络 I/O 趋势 | 使用入站、出站速率表达式进行范围查询 | bits/s |
| 资源趋势 | 趋势当前值 | 对应趋势表达式的即时查询结果 | - |
| 资源趋势 | 趋势平均值 | 对应趋势表达式在所选时间范围内的 `avg_over_time` 结果 | - |
| 资源趋势 | 趋势峰值 | 对应趋势表达式在所选时间范围内的 `max_over_time` 结果 | - |

说明：表中 `$host_ip` 和 `$host_name` 为查询变量，对应后续为 node-exporter 序列补充的标签；文件系统和磁盘设备筛选条件需按实际挂载点、设备名配置。

### k8s部署方式

k8s部署时，可以使用Prometheus的服务发现，服务发现会携带上节点的一些基本信息：

- 主机名：__meta_kubernetes_node_name
- 主机IP：__meta_kubernetes_node_address_InternalIP
